The palette the original never parses

M20, the ending scene, is the last unbuilt phase D milestone. This round read all of END.EXE's own logic (main.c, tick.c, stars.asm) and built the first piece: its own, separate palette.

Its own executable, not part of GAME.EXE

END.EXE is a fully separate program that GAME.EXE starts with four arguments at the end of the game. It reloads its own graphics driver and its own font, so nothing this project has already measured covers it directly. Plenty of already-built formats turn out to be reusable as they stand: LZW, the .SHP container, the song files.

ENDPAL.LBM: a container the original never parses

The file is an ordinary Deluxe Paint ILBM palette, but PAL_load never reads its own tags at all: it jumps straight to byte 0x20, reads 784 bytes, and shifts the 768 byte palette right by two, eight bits down to the DAC's six. That only works because IFF's own BMHD chunk is always a fixed twenty bytes, so the CMAP data always lands in the same place.

This project does not trust that same fixed offset blindly: U6LbmPalette checks the FORM/ILBM/BMHD/CMAP tags in order and only then reads from the same spot the original's own arithmetic reaches anyway. The discriminator is the shift itself: read raw, most of the 256 colours exceed the DAC's own ceiling of 63, and only the shifted bytes fit six bits across all 768.

Two formats, no new work

END.SHP and END.M were already on this project's own file lists, and their container format is already measured and tested elsewhere, the same 396 frames across 12 files the tile and shape codec already proves exact. The ending's own ten pictures decode straight away.

The star field, measured in full

64 stars fly out from the Codex's own centre, speed rising with distance, and a star that leaves its own field is reborn at a random place. The random source, though, is Turbo C's own rand(), not the game's OSI_rand, and its algorithm is not measured anywhere in this decompilation. Named as a deliberate simplification: this project's own shared generator stands in, since the original's own stars are not reproducible between playthroughs either.

What was not measured this round

The scene state machine (16 scenes, the two lenses' own rise and fall, three dissolve triggers) is read in full but not built. The 16 text pages carry no offset comment anywhere in the decompilation, unusually. The first page was still found directly in the owner's own END.EXE bytes, exactly once, and the same technique works for the other 15, but nobody has done that yet.
