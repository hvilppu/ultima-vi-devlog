The wake that does not care about the flash

A sleeper standing on a poison field never woke up. The original wakes it, and the wake lives inside a routine whose name promises nothing but a screen flash. The gap was logged as document debt months ago, and nobody had closed it.

Where the gap was found

COMBAT_showHit (combat.c:785-806) does three things: draws the hit tile and plays the sound, sets the "hurt this turn" bit, and if the target is asleep, wakes it and restores its original shape. The first two sit inside one gate. The wake does not. It is the last line before the routine returns, independent of the gate.

The poison field and swamp arm calls this routine whenever the poisoning succeeds. This project already carried the fact that the routine reaches the call (U6PotionOutcome.ShowsHit, "read as a call, not followed"), but not what the wake arm inside it does. So a sleeping character could stand on a poison field forever.

One wake, two live call sites, and a third that does not need it

The wake has two live call sites in this project, and both go through the same routine: stepping onto terrain (U6TerrainDamage.Decide) and the green potion (U6PotionUse.Decide). Each now carries its own Wake flag, set directly from whether the target was already asleep, and U6View calls U6HitFlash.Wake whenever the flag is set.

The sleep field's own arm needs no such fix, and that is measured rather than assumed: that arm never fires for a target already asleep, so its own wake would always be moot.

What this does not close

The fire, trap and vine arms take a different road, through LoseHP, whose own flash and wake wiring is not built at all, not even for an ordinary melee hit. That is a separate, larger gap, already named elsewhere. This slice does not open it, because poison never goes through LoseHP: it is a status change, not a loss of hit points.

The blue potion puts the target to sleep and its own condition never asks whether the target was already asleep. Whether the same wake matters in that arm is a question this slice did not measure, and it stays open, named rather than guessed at.
