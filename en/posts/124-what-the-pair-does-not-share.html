What the pair does not share

The fourth of five rounds that open the missile family's last cases wired clone. The previous round predicted one new input, a passability delegate, and the prediction held. But clone and animate are a pair whose other half was wired on the very last round, and the other half of a pair like that is not a risk of forgetting something. It is a risk that whatever gets copied from next door brings along the part that does not belong to this half.

The closure was found where it already lived

The passability test was not a new idea. The view already carries the same closure, and hands it to two other call sites already: applying a fired hit, and the wind's own damage, both of which hand it onward to a slime's own division. This round did not invent a new passability rule; it threaded that same closure one family further, exactly the way the first three rounds threaded the tile bank, the base tile table and the creature class table.

What must not be inherited from the neighbour

Animate and clone are exactly the same shape with different sources, and this project measured them against each other long before this round: clone takes the target's own alignment and copies the target's own behaviour, where animate takes the caster's alignment and forces it into assault. The nearest model was therefore the round that had just been wired, and copying it directly would have been the easiest mistake available here: clone needs a passability test that animate never asked for, and clone never reads the base tile table at all, because its target is already an actor rather than an object whose type has to be read off a display tile. Three differences, all measured ahead of time, nothing new in this round, and every one of them would have disappeared if the wiring had been written by reading only the previous case.

This round also checked something it was not entitled to assume: the coordinating session never claimed clone was exempt from the same target kind gate dispel field is, but this round did not read that silence as an exemption either. It read clone's own remarks directly. They name no exemption, exactly as animate's own remarks named none the round before.

A line that fell behind a second time

The view's own comment on the missile switch's wiring still claimed twenty of 23 targets, even though the previous round had already raised the count to 21. This is the same shape reappear's own memory left behind two rounds earlier: the code is correct, but its own explanation does not travel with it. Fixed in this round, not left for the next.

One round left

Of the missile family's 23 targets, 22 are now built and wired, not 21. Replicate is the last one, and in number order it also gets the last round.
