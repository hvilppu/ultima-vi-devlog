What is actually on the disks

Fifty-odd data files, no documentation, and one compression scheme standing between me and all of it.

The installed game is a flat directory of short, uppercase names with no extensions or unhelpful ones: MAP, CHUNKS, TILEFLAG, BASETILE, LOOK.LZD, OBJTILES.VGA. Seven small files named U6.1 through U6.7 turn out to be the labels of the original floppies, and they are quietly useful: they name the disks Program, Introduction, Endgame, Game, Map and Populace A/B, which tells you how the developers grouped their own data before you have read a single byte of it.

Most of the directory is redundant. The same artwork ships five times over, once per graphics standard of the era: CGA, EGA, Tandy, Hercules and VGA. That is 89 files that can be ignored outright. What is left is about fifty that matter.

One format unlocks half the directory

The first real obstacle is that many files start with four bytes that look like a length and then dissolve into noise. LZMAP begins with a 32-bit value of 32,256. There is also an uncompressed file called MAP in the directory, and it is exactly 32,256 bytes long.

That is the whole hint. The files are LZW-compressed with a four byte header giving the decompressed size, and the compressed stream is a run of variable-width codes packed least-significant-bit first: nine bits to start, growing to twelve as the dictionary fills, with code 256 resetting the dictionary and 257 ending the stream.

Writing the decompressor is half an hour. Verifying it is the interesting part, and the header makes that free: every file declares what it should expand to, so the decoder can be checked against eight different files at once without knowing anything about what they contain.

All eight decoded to exactly the declared size on the first run. Those sizes and their checksums became the first regression tests in the project, and they have not moved since.

Names, for free

LOOK.LZD is the file that makes everything else legible. It is a flat run of records: a 16-bit tile number followed by a zero-terminated string. Tile 1 is grass, tile 15 is water, tile 51 is a tree.

There is one wrinkle that turns out to be a small piece of 1990 cleverness. Some names carry two marker characters, / and \. Everything before the slash is shared, the part between the markers finishes the singular, and the part after finishes the plural. One string, both forms, no second table. A loaf of bread and loaves of bread come out of the same seventeen bytes.

Five hundred and thirteen tiles carry a name. That table became the oracle for nearly every discovery that followed: whenever a bit field needed interpreting, the question became which tiles have this bit set, and what are they called?
