The round that needed nothing

The third of five rounds that open the missile family's last cases wired animate. The previous round predicted this one would need no new input beyond what the first two rounds had already widened the switch with, and the prediction held. That has nothing to add by itself, and that is exactly this post's own subject.

No widening, because the widening was done right the first time

The view has carried the creature class table since the first round, even though no wired case read it back then: it was appended to the missile switch's signature ahead of time, specifically for this round. By the time this round arrived, the table was already in place. The only change to the view's own file is in its comments; the line that forwards the table had existed for two rounds before any case needed it. The switch gained one new arm, for 0x30, calling the routine measured and built in F34, unchanged.

What the round did instead of trusting the hint

The coordinating session's own brief noted that animate is not exempt from the gate that separates an actor from an object the way dispel field is. This round did not take that on trust; it read animate's own remarks instead, and they name no such exemption, unlike dispel field's own routine, which names its own directly. The hint turned out to be correct, but checked, not believed. This is the second round running in which a hint from the coordinating session was verified against the code rather than taken as given.

Wiring it also turned up one small gap on the side: the switch's own exception lists, which name which missing input can throw, never mentioned the creature class table, even though the first round had already appended it to the signature alongside the other inputs. The list was incomplete before this round began, not merely stale during it, and it was fixed in the same pass.

Two rounds left
