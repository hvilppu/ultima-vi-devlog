Eight rooms light up

The previous slice opened a door onto an empty room: a number knows its own family, but not where its own case sits inside it. This slice measured that place, in numbers, then found its own mistake about what it was allowed to write down, and fixed it in the same session. The result: eight spells out of eighty now actually do something, and the remaining eleven known cases stay dark for two reasons that have nothing to do with what the first version claimed.

A trap that already cost once

The dispatcher's own case labels are separated by comments, so splitting on the labels treats every comment block as its own block and breaks a fall-through branch at each one. The first extraction produced twenty five cases that appeared to call nothing, which is the shape of an extraction fault, not a finding about the real game. The classification script, already fixed once before, was extended for this slice with a new part that resolves every case label to its own number internally and prints only numbers, never a name beside one. Run, it produced exactly the same tables as the ones read by hand from the decompilation's own switch block: a cross check passed before a line of code was written.

A rule read too widely, then fixed

This slice's own first version opened two of the five rooms and named the other three entirely unwired, claiming that writing their own case would be exactly the name to number tie this project has refused for nine slices running. That was the wrong reading, and it was corrected inside the same session. The rule covers the game's own published text: eighty display names, a spell's own word, the dialogue, the book text. It does not cover code identifiers, ours or the decompilation's own: this project has already used them for nine slices in its own documents. What was actually missing was never permission to write the tie; it was that none of the nine earlier slices ever had, because each read a handler one case at a time and described it in prose.

After the fix, every one of the three remaining families' own case resolves straight from the decompilation's own numbers, cross checked against each handler's own internal branch.

Eight rooms, with real data

In the missile family the range is eight in every one of the 23 cases, a constant rather than a table, and the target kind splits six against seventeen. The gate now runs for real, with the view's own geometry, the target object read from the first actor on the chosen square, the same simplification the party-ring effect already uses. The world still does not change, because none of the twenty three effects is built, but the gate itself is now the real one.

Of the eight duration rooms, six now write the real effect slot, straight through a raw index rather than by picking one of the already named values. Two rooms are named refusals rather than stand-ins: one would need a command that is not built, the other would need a print that is not built.

Of the four party-ring rooms the fix opened up, two now run for real: one reads invisibility state this project already tracks and moves a worn ring to the inventory, the other uses this project's own fourth measured resistance formula and writes the target's own mode and alignment. These are the first and second time in the whole M14 spell arc that casting actually changes the world.

Eleven stay dark, for two unrelated reasons

The party-ring family's other two cases would each need a monster class classification (undead for one, immune to death spells for the other) that nothing in this engine tracks on any actor, independently of which raw number the case is. The wind's four cases and the summon's two are now known by number, but each family needs something else besides: the wind's own path has never been measured, and wiring the summon's own generator in would need reordering it ahead of its own placement draws, which would shift every later roll the shared generator makes. Supplying a stand-in for either was considered and rejected: this project has made that exact mistake three times before, and three was enough.
