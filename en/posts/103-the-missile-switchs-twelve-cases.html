The missile switch's twelve cases

One switch answers for 23 spells, and this project answered all 23 with a single blanket refusal: "not built yet". The twelfth of them calls an effect that already has its own, tested implementation somewhere else, waiting for something to actually call it. This slice was writing that call, not inventing a new rule.

23 spells, 12 call sites

The dispatcher's own switch has exactly twelve case groups for this family, not 23: several spells fall through into one call. Nine actors on a generic tile, four objects on a generic tile, two actors on an arrow tile, eight with a tile of their own: 9 + 4 + 2 + 8 = 23, matching the dispatcher's own family table. A reading that counted only the call sites would have said twelve, and that was the first thing proven wrong, not assumed.

Three findings a straightforward port would have gotten wrong

Dispel's own return is inverted against this file's usual convention: zero means something was cleared, one means nothing was. Recasting charm on an already charmed target frees it instead of charming it again, and the result is left at its default because the original never assigns it in that branch. Heal always consumes its random roll, even on the path that ends up setting the total straight to the maximum instead of adding the roll; great heal never rolls at all. All three were already correct in effects built earlier; this slice only had to apply them in the right order.

One new flag, not a second lookup

The sleep spell needed a sixth class flag, immune to sleep, and it was the same shape the previous slice already used for fire and poison: one more bit added to the same method, not a second reader beside it. The winds' own wiring widened its type to match, even though none of the four winds ever reads the new flag.

Two named gaps, not two guesses

A doused torch disappears entirely in the original, and an ignited powder keg arms a fuse. Neither fits in this wiring: this project has no general object deletion primitive yet, and the fuse belongs to the world clock, not to the spell wiring. Both effects' own frame write still applies; only the deletion and the fuse value are left as named gaps. Douse and ignite are not even reachable in play right now anyway, since both demand an object as a target and the spellbook's own targeting can only ever select an actor.
