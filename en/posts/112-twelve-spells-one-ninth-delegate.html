Twelve spells, one ninth delegate

Help, reappear, telekinesis, pickpocket, seance, hail storm, web, wing strike, resurrect, slime, tremor and insect swarm: twelve spells, each measured, built and tested in its own slice, and each entirely unreachable from the spellbook. The fix was not any one of the twelve. It was the dispatcher, which had no way to send a call outside its eight fixed families, and the fix is one new delegate, not nineteen.

Dormant code, the largest pile yet

Five slices in a row measured and built one more spell that shares nothing with any of the eight shared families: reappear, slime, tremor, wing strike, insect swarm, hail storm, resurrect, help, seance, telekinesis, pickpocket, web. Each slice correctly reported the same thing: the dispatcher that turns a spell number into the right handler carries eight fixed family delegates and has no slot for an own branch. Nobody invented a stand in for that missing slot, which was the right call every single time, but the result was twelve built, tested and completely unreachable handlers at once, more dormant code than this project has ever carried at the same time.

Dormant code is not as harmless as it first looks. It is correct and tested today, but it turns into a defect the moment something starts calling it wrong, and the longer it waits the more certain it is that somebody will have to re-read all twelve handlers just to remember why they are waiting.

One delegate, not nineteen and not a table

The fix is one ninth delegate on the dispatcher, with the same signature as the other eight: a spell number and a flag for whether the target is already given. The dispatcher's answer is now one of eight families, this ninth own branch, or a refusal for a number that is not a spell at all.

Two other shapes were obvious and both were rejected by name. Nineteen delegates is the shape the signature already suggests, and at nineteen it is absurd: every call site would carry nineteen parameters to say nothing new. A per-number handler table inside the engine fails on its inputs rather than on taste: the twelve handlers need the object world, the characters, the clock, the generator and the tile bank in twelve different combinations, and the table would have to accept the union of all of them, which is most of the game.

One delegate is also what the original itself does. Its own dispatcher is a single switch in which each own branch is its own case calling its own routine, with the inputs already in scope right where the game state lives. In this project that place is the view, not the engine, so the per-number switch lives in the view. The dispatcher still resolves only a family, not a case, exactly the finding recorded when the dispatcher was first wired, dozens of slices ago, and that finding does not change here.

Twelve reachable, seven named lines

Twelve numbers now resolve to the new delegate and actually call their own, previously measured handler: help, reappear, telekinesis, insect swarm, pickpocket, seance, hail storm, web, wing strike, resurrect, slime and tremor. Seven spells remain with no handler measured at all: create food, wind change, x-ray, enchant, gate travel, wizard eye and armageddon. None of them was guessed at, not even the ones whose name suggests an obvious behaviour, because several of this project's own measured findings so far have been exactly where the obvious behaviour was wrong. Each of the seven is its own named line, so the slice that measures and builds one of them deletes exactly that line and touches none of the other six.

Three of the twelve cannot yet succeed

An honesty this post does not want to skip: three of the twelve callable spells cannot yet succeed in play, because the view is missing some input the measured handler demands. Neither is a stub, and neither had its behaviour changed during the build: the real handler runs for real and takes its own, already measured refusal.

Telekinesis never asks for a push direction, because the view has no direction prompt sub-mode. The crank, the lever and the weightless object's refusal all work regardless, since none of them needs a direction. Pickpocket's second selection, the one where the player picks an item out of the victim's own inventory, is always absent, because there is no sub-mode for it in the view, so the spell always takes its own measured refusal for that state. And reappear's own memory is always empty, because vanish, the spell whose job is to fill it, is not itself reachable through the missile wiring. Reappear therefore always asks an honestly empty memory, rather than hiding the gap.
