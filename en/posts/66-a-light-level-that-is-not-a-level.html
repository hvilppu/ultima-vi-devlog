A light level that is not a level

Eight spells that share one three line shape, M14's slice D6. Six of them are duration spells, two act at once. The decompilation names one effect slot wrong in its own comment, and the only place in the whole game that reads that slot is one line of code, which was enough on its own to refute it.

A comment that is wrong

Light and great light write the same effect slot, number 0, and the decompilation comments it as a "light level". Exactly one place in the entire game reads that slot, the world clock's own lighting test, and it does not read a number out of it: it asks whether the slot is empty or not. A truth value, not a brightness. So light and great light are exactly the same effect for as long as either lasts, not two different strengths of light: 100 minutes for one, 255 for the other, and nothing else differs. This is not the comment restated in other words, it is its refutation: one line was enough, because it was the only line that could ever have shown otherwise.

Eight spells, one shape

The spell dispatcher map (slice D2) named eight spells under one shared handler, MagicalHalo: the caster's own halo, the casting effect for the spell's circle, and one line of its own per spell. Six of those lines write one effect slot and a number of minutes; two do not write a slot at all. Peer uses the gem and prints message 7; locate prints the location and nothing else. One built shape covering eight cases, not eight handlers that would each repeat the halo and the casting effect and eventually drift apart.

Peer's own gem use turned out to be something other than the brief claimed, once looked at more closely: the brief named it a routine M13 had already built, but the "use" command's own table lists UseGem as not built, and M13's last commits built a ladder and an open barrel, not the gem. The routine is taken as an injected delegate instead of being built here, the same shape every other routine built elsewhere in this project already uses.

Two clocks that start differently

Light and great light tick the world clock by zero minutes, which refreshes the time dependent state without advancing anything: the light takes effect at once rather than waiting for the next minute to pass. The other four duration spells, infravision, negate magic, time stop and eclipse, do not. The engine does not own the world clock, so this is built as a flag in the outcome rather than a call to the clock from inside the engine assembly.

The storm cloak collision

A worn storm cloak writes the same effect slot, 13, to 1 on every world clock tick, for as long as anyone in the party wears it. Negate magic writes 20 to that same slot. Neither measurement, the cloak's or the spell's, mentions the other: the collision only shows up by noticing both touch the one byte. So casting negate magic while the cloak is worn leaves one minute instead of twenty at the very next tick, and nothing tells the player. Recorded, not fixed: the cloak's own rule belongs to whichever slice eventually measures the storm cloak.
